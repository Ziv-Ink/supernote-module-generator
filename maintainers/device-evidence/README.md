# Historical device evidence

This directory preserves device-backed qualification records for the implementation
released publicly as `sn-module-gen` 0.1.0. V4 was that implementation's internal
pre-public qualification codename; it is not a separate public product line or a
migration target.

The dated evidence keeps its original V4 filenames and wording so its recorded
commands, firmware identities, results, and hashes remain historically accurate.
Do not rewrite those records to use later public terminology.

- [`v4-device-canary-2026-08-27.md`](v4-device-canary-2026-08-27.md) records the
  authorized lifecycle and reload canary.
- [`v4-bounded-note-doc-2026-08-27/`](v4-bounded-note-doc-2026-08-27/) contains
  the bounded NOTE and DOC acceptance evidence and its own evidence index.
