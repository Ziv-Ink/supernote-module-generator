This is the complete base-test disposition for the raw historical replay in
`/private/tmp/q2-r11-historical-full.log` (1,287 passed, 17 skipped, 575
failed). Each listed base name covers every failing parameterized row for that
base. The raw pytest summary prints 578 `FAILED` node-id lines because three
release-qualification subprocess failures are reported both inside the parent
case and again in the outer summary; the JUnit/pytest result is authoritative.

The list is deliberately mechanical: the set of base names below equals the set
of failed base names parsed from the raw log. Passing migrated tests are not
listed as failures. No failed case is silently treated as evidence that the
current contract passes.
